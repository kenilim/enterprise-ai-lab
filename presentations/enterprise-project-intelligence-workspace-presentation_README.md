# Enterprise Project Intelligence Workspace — HTML Presentation

## Files

- `enterprise-project-intelligence-workspace-presentation_v0.1.html`

## Purpose

A self-contained, offline-capable 16:9 HTML presentation for internal knowledge sharing.

It covers:

- the enterprise information-fragmentation problem
- hallucination risk caused by incomplete retrieval
- the proposed ChatGPT-style project workspace
- the evidence-to-application workflow
- the air-gapped enterprise architecture
- the personal lab environment and installed tooling
- completed experiments and key learning points
- the Docling baseline and next extraction experiment
- governance controls and roadmap

## Usage

Open the HTML file in a browser.

Keyboard controls:

- Right arrow, Down arrow, Space, Page Down: next slide
- Left arrow, Up arrow, Page Up: previous slide
- Home: first slide
- End: last slide
- F: fullscreen

Use the **Print / PDF** button to export a PDF snapshot.

## Suggested repository location

Store the presentation under:

`presentations/enterprise-project-intelligence-workspace-presentation_v0.1.html`

## Design

- self-contained HTML
- no external JavaScript libraries
- no external CSS files
- no internet connection required
- 16:9 presentation layout
- browser fullscreen mode
- print-to-PDF support
