# Enterprise AI Development Lab

This workspace is used to learn an end-to-end enterprise-style AI development workflow.

## Projects

### 01-doc-to-spec-pilot
Local document ingestion and specification drafting:
- Parse PDFs, DOCX, PPTX and XLSX files locally
- Preserve source evidence
- Export structured Markdown and JSON
- Draft requirements, design and task files using local models

### 02-app-build-pilot
Application development:
- Build from approved specifications
- Use OpenCode with an OpenAI coding model
- Test locally
- Package and run with Docker

## Logging Convention

Log filenames follow:

## Security Boundary

Use synthetic, public or sanitised documents only.
