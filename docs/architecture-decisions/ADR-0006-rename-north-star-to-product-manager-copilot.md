# ADR-0006: Rename North-Star Product to Product Manager CoPilot

## Status

Accepted.

## Decision

Rename the north-star product vision from:

`Enterprise Project Intelligence Workspace`

to:

`Product Manager CoPilot`

## Reasoning

The name should describe the user problem being solved.

The target product is not merely a document repository or generic knowledge
workspace.

It is intended to help product managers:

- organise fragmented project evidence
- ask grounded questions
- find source material
- detect stale or conflicting information
- generate draft requirements and delivery artefacts
- understand the impact of new information
- review versioned changes
- hand approved bounded tasks to development agents

## Learning-Journey Context

This lab is being built hands-on by a non-technical product person with basic
and dated coding knowledge.

The product manager defines:

- the problem
- the constraints
- the learning sequence
- the north-star product
- the required controls
- the review gates

An AI copilot supports:

- research
- explanation
- script generation
- troubleshooting
- documentation
- iteration

## Implication

The lab should visibly demonstrate that product builders with disciplined
requirements and strong problem framing can independently learn, prototype and
evaluate a larger portion of the delivery workflow.

This does not remove the need for engineers.

It improves the quality of the handoff to engineers and increases the speed at
which product builders can test ideas.
